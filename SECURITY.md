# Security

- Do not commit passwords, Steam session cookies, browser profiles, API tokens, private keys, or personal account data.
- Do not share browser storage or authentication files when asking for support.
- Keep artwork and personal posting history outside the repository unless you have the rights and a clear reason to publish them.
- This project is intentionally local and read-only. It does not authenticate to Steam or send requests to Steam services.
- Report a security concern privately to the repository owner rather than publishing sensitive details in an issue.
